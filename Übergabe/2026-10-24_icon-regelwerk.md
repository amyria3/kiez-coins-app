# Icon-Regelwerk (2026-10-24, von Daria festgelegt)

Gehört nach Documentation: eigene Datei `kiez-coins/design/ICON-REGELWERK.md`, Verweis in `kiez-coins/ENTSCHEIDUNGEN.md`.

## Grundregel

Jedes Icon hat in einem Look genau eine Bedeutung, und jede Bedeutung hat genau ein Icon. Wer ein Icon neu einsetzt, prüft es gegen diese Tabelle. Eine neue Bedeutung bekommt ein neues Icon und eine neue Zeile.

## Instagram-Look

| Icon | Einzige Bedeutung | Wo |
|---|---|---|
| Herz | Gefällt mir | Aktionsleiste am Beitrag |
| Eigenes Profilbild | Was Du so machst (Dein Profil) | Kopf im Feed, Dein Konto |
| Papierflieger | Senden: Teilen, Kommentar senden, Nachricht senden | Beitrag, Detail, Kommentare, Chat |
| Sprechblase rund | Kommentare | Aktionsleiste am Beitrag |
| Sprechblase mit Zeilen | Chats | Kopf im Feed, Leiste |
| Haus | Feed | Leiste |
| Zwei Personen | Gruppen | Dein Konto, Gruppenkarte, Profil-Reiter „Gruppenaufgaben“ |
| Stecknadel | Ort | Challenge, Profil, Kiez wählen |
| Kettenglied | Webseite | Profil einer Person |
| Plus | Hinzufügen, Neu | Foto hinzufügen, Gruppe gründen, Edenstein +1 |
| Haken | Erledigt oder angenommen | Challenge-Detail, Profil-Reiter „Angenommen“ |
| Kamera | Foto: Erstellen beginnt mit dem Foto, Foto aufnehmen | Leiste, Formulare |
| Zahnrad | Verwalten | Beitrag, Gruppe, Challenge-Detail |
| Raster | Deine Challenges | Dein Konto, Profil-Reiter „Erstellt“ |
| Burger | Menü | Leiste |
| Drei Punkte | Weitere Aktionen (Melden) | Challenge-Detail |
| Brillant | Edenstein (Angabe, kein Knopf) | Gruppenaufgaben |
| Zwei Münzen | Bounty in Euro (Angabe, kein Knopf) | Beitrag, Detail |

Texte statt Icons: „Alle“ führt zur Übersicht der Gruppen, „Speichern“ speichert ein Feld.

## Angaben und Knöpfe

- Knopf: Icon in Icon-Größe (24 pt bei 360 pt Breite), mindestens 44 pt Druckfläche.
- Angabe: Icon kleiner als die Knöpfe, direkt neben seiner Zahl (4 pt), ohne Druckfläche und ohne Bewegung.

## Weitere Festlegungen vom selben Tag

- Der Kopf im Feed (Schriftzug, Profilbild, Chats) bleibt im Instagram-Look stehen, da er wichtige Knöpfe trägt. Nur beim Erstellen geht er weg.
- Zurück ohne Verlauf führt in allen Seiten eine Ebene höher (`useGoBack`), auch nach dem Speichern und im Challenge-Detail.
